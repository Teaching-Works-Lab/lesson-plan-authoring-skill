# Lesson Record Contract

Each meeting must be teachable, observable, and assessable.

Required functional slots:

- topic/chapter/week/hours;
- knowledge hierarchy image;
- knowledge, ability, value objectives;
- ideology and professional/innovation integration;
- key/difficult points;
- methods/tools;
- 100-minute sequence;
- explicit teacher action and student action;
- independent student product;
- debug/test/review step;
- evidence retained;
- assessment/goal mapping;
- in-class check, summary, homework, attendance;
- post-class reflection prompt only;
- references.

For programming courses, avoid a lecture-only middle. The 100-minute plan should contain meaningful student coding/testing time and an inspectable source-code or test artifact.
